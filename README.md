
For the reviewer assessment, I relied on the Group Gaussian Mixture Scenario Generation TVR and the subsequent issue closure assessment. There are no open Group validation findings being transferred to SCB AG.
On the model limitations, the Group limitations are relevant for SCB AG. The reference-variable limitation already has a compensating control which was assessed by GMV as sufficient. There is also a limitation related to structural market changes which currently has no corresponding AG-level compensating control. Since the model is rated RR3, we raised an identified concern to assess whether this limitation is material for the SCB AG portfolio and, if material, implement an appropriate compensating control. The limitation related to incomplete correlation capture is considered inherent to the methodology.
Regarding model performance, the model has not yet been put into use at SCB AG, so there are currently no local monitoring results. In line with the Group framework, performance of models used to backfill VaR inputs is monitored through the corresponding downstream VaR models.
On the model risk rating, the Model Champion proposed materiality 3 based on the SCB AG Model Family Standard. We noted a discrepancy between the Group and AG approaches. At Group level, GMV challenged the original materiality 3 assessment and reduced it to 1 based on the actual stressed-VaR impact of the model. The AG approach assigns materiality 3 more conservatively based on the role of the model in the VaR framework, without explicitly considering the actual impact of this specific model.
For the current attestation, we retain materiality 3 in line with the existing AG standard, but we raise an identified concern to review the AG materiality approach, align it with the Group framework where appropriate, and reassess the materiality rating afterwards.
The uncertainty rating is C, consistent with the Group TVR. This is mainly driven by Model Specification, which is rated C, while Input Data, Implementation and Operating Environment, and Model Performance are rated B, and Event Risk is rated A. Based on materiality 3 and uncertainty C, the final SCB AG model risk rating is RR3.
Overall, the reviewer assessment is Conditionally Acceptable for the ICAAP Feeder Model use case, in line with the Group validation outcome.
There are two remediation actions. The first is to review the materiality-rating methodology and reassess the rating by 31 December 2026. The second is to assess the materiality of the model limitations at SCB AG portfolio level and implement compensating controls where required, with a target date of 31 March 2027.
